# PCController

Управляйте компьютером с телефона одним пальцем: тачпад и клавиатура без настоящей мыши и клавиатуры.

## Для кого это

Приложение сделано для людей, которым трудно или невозможно пользоваться обычной мышью и клавиатурой: например, из-за двигательных нарушений, травмы, тремора или ограниченной подвижности рук. Если вы можете касаться экрана телефона, вы можете управлять компьютером.

Телефон превращается в тачпад и клавиатуру. Всё управление рассчитано на **одно касание одним пальцем**: не нужно нажимать две клавиши сразу, делать точные жесты двумя пальцами или держать устройство двумя руками.

Если вам нужно управление голосом, кнопками-переключателями или взглядом, этого пока нет: подробнее в разделе [«Что пока не поддерживается»](#что-пока-не-поддерживается).

## Что умеет

- **Тачпад.** Коснулись экрана: левый клик. Коснулись и подержали: перетаскивание. Правый клик и режим точного наведения вынесены в отдельные крупные кнопки.
- **Точное наведение.** Одной кнопкой курсор замедляется втрое, чтобы попадать в мелкие элементы. В обычном режиме курсор разгоняется, когда палец движется быстро.
- **Прокрутка.** Кнопки со стрелками: нажали и держите, страница листается сама.
- **Клавиатура на экране.** Русская и английская раскладки, ряд F1–F12, стрелки, Esc, Del, Home, End, PgUp, PgDn. Удержание клавиши повторяет её (удобно для стрелок и Backspace).
- **Сочетания клавиш без одновременного нажатия.** Shift, Ctrl, Alt и Win «залипают»: нажали модификатор, затем нужную клавишу, держать две сразу не нужно.
- **Быстрые команды.** Копировать, вставить, сменить окно, закрыть вкладку, сохранить и другие сочетания в одно касание.
- **Работает на экране входа и в окнах «Разрешить этому приложению вносить изменения».** Можно самостоятельно включить компьютер, ввести пароль и подтвердить запрос администратора, не прося помощи.
- **Компьютер находится сам.** Приложение ищет его в сети Wi-Fi. Если не нашло, можно ввести адрес вручную.
- **Запускается вместе с Windows.** Настроить нужно один раз, дальше компьютер всегда готов к управлению.

> [!WARNING]
> Сервер не проверяет, кто к нему подключается, и не шифрует данные. Пользуйтесь только в доверенной домашней сети. Подробнее в разделе [«Безопасность»](#безопасность-прочитайте-до-установки).

## Как установить

Установку достаточно сделать один раз. Всё нужное лежит на странице [релизов](https://github.com/savi0810/PCController/releases/latest).

1. **На телефон.** Скачайте `PCController.apk` и установите его. Android попросит разрешить установку из этого источника, согласитесь.
2. **На компьютер.** Скачайте `PCController.Server.exe`, запустите двойным щелчком и нажмите «Да» в окне, которое спросит про права администратора. Программа сама скопируется в папку `C:\Program Files\PCController` и добавит себя в автозапуск. Больше запускать её вручную не нужно.
3. **Подключитесь.** Телефон и компьютер должны быть в одной сети Wi-Fi. Откройте приложение, подождите несколько секунд и нажмите на название вашего компьютера в списке. Если его нет, введите IP-адрес компьютера в поле слева. Узнать его можно в свойствах Wi-Fi, строка «IPv4-адрес», или командой `ipconfig`.

Нужно: компьютер с Windows 10 (версия 1607 или новее, 64-разрядная) и телефон на Android.

### Если Windows предупреждает об опасности

Файл `PCController.Server.exe` пока не имеет цифровой подписи, поэтому при первом запуске Windows может написать «Защитник Windows предотвратил запуск неопознанного приложения». Нажмите «Подробнее», затем «Выполнить в любом случае». Некоторые антивирусы тоже могут насторожиться, потому что программа добавляет себя в автозапуск и работает с повышенными правами. Исходный код открыт: вы или ваш помощник можете проверить его и [собрать программу сами](#сборка-из-исходников).

### Если компьютер не появляется в списке

- Выключите VPN на телефоне и на компьютере: он часто мешает найти устройства в сети.
- Проверьте, что оба устройства подключены к одной сети Wi-Fi (не к гостевой) и что в настройках роутера не включена «изоляция клиентов».
- Введите IP-адрес вручную: так подключиться всегда получится.

### Как удалить

Откройте командную строку на компьютере и выполните:

```
"C:\Program Files\PCController\PCController.Server.exe" --uninstall
```

Команда уберёт автозапуск и правило брандмауэра. Папку `C:\Program Files\PCController` после этого можно удалить вручную.

## Безопасность: прочитайте до установки

Сервер **не проверяет, кто к нему подключается, и не шифрует передаваемые данные**. Любой человек в той же сети Wi-Fi, у кого есть приложение, сможет управлять вашим компьютером, в том числе вводить пароль на экране входа. Поэтому используйте PCController только в доверенной домашней сети и не включайте его в общих сетях (кафе, вокзалы, общежития, гостиницы). Защита с подключением по коду в планах.

## Что пока не поддерживается

- Управление голосом, кнопками-переключателями и взглядом. Приложение рассчитано на касания экрана телефона.
- Компьютеры с macOS и Linux (Linux в планах).
- Мобильное приложение на iOS.

## Как это работает

Телефон отправляет короткие JSON-сообщения (движение, клик, символ, клавиша с модификаторами) по WebSocket. Сервер разбирает их и передаёт в Windows тем же способом, каким это делает настоящая клавиатура. Чтобы телефон сам находил компьютер, сервер сообщает о себе в сети по mDNS.

Так выглядят сообщения: движение курсора и сочетание Ctrl+C.

```json
{ "Type": "Mouse", "Action": "Move", "X": 4, "Y": -2 }
{ "Type": "Keyboard", "Action": "Char", "Char": "c", "Modifiers": ["Ctrl"] }
```

Экраны входа и запросы администратора (UAC) нарисованы на отдельном защищённом рабочем столе, и обычная программа не может отправить туда ввод. Поэтому при запуске Windows сервер запускает свою копию с правами SYSTEM в сессии пользователя, и эта копия переключается на тот рабочий стол, который сейчас принимает ввод.

## Для разработчиков

### Технологии

| Часть | Что использовано |
| --- | --- |
| Приложение | Expo SDK 57, React Native 0.86, TypeScript, expo-router, Reanimated 4, Gesture Handler, NativeWind (Tailwind CSS), React Native Reusables, react-native-zeroconf, React Compiler, EAS Build |
| Сервер | .NET 10, ASP.NET Core (Kestrel, WebSocket), Makaretu.Dns.Multicast (mDNS), InputSimulator, вызовы Win32 API (user32, advapi32), Планировщик задач Windows, PowerShell |

### Что здесь было интересно делать

- **Ввод на экране входа и UAC.** Нужны процесс с правами SYSTEM в сессии пользователя, подключение потока к рабочему столу ввода (`OpenInputDesktop` и `SetThreadDesktop`) и автоматический перезапуск при смене сессии.
- **Установка одним запуском.** Exe сам копируется в Program Files, регистрирует задачу в Планировщике, добавляет правило брандмауэра и обновляется при повторном запуске.
- **Управление одним пальцем.** Касание, удержание и перетаскивание обрабатывает Gesture Handler, кнопки умеют автоповтор при удержании, а модификаторы клавиатуры «залипают».
- **Минимальная задержка.** Небольшие пакеты уходят сразу (TCP NoDelay), а курсор разгоняется в зависимости от скорости пальца.
- **Задел под Linux.** Ввод спрятан за двумя небольшими интерфейсами, чтобы можно было добавить Linux новой папкой, не трогая остальной код.

### Архитектура проекта

```
PCController/
├── PCController.Client/          приложение для Android (Expo)
│   ├── app/                      вход и переключение экранов
│   ├── screens/                  экраны подключения и управления
│   ├── features/                 connection, mouse, keyboard, actions, help
│   ├── shared/                   общие компоненты (PressBox, кнопки, ui)
│   ├── services/                 WebSocket и поиск по mDNS
│   └── core/                     протокол, автоповтор, тема
└── PCController.Server/
    └── PCController.Server/      сервер для Windows (.NET)
        ├── Transport/            WebSocket
        ├── Handlers/             разбор и выполнение команд
        ├── Input/                интерфейсы и реализация ввода для Windows
        ├── Discovery/            объявление компьютера по mDNS
        └── Protocol/             формат сообщений
```

### Сборка из исходников

**Сервер** (нужен .NET 10 SDK, консоль от администратора):

```
cd PCController.Server\PCController.Server
dotnet run
dotnet publish -p:PublishProfile=FolderProfile
```

`dotnet run` запускает сервер как обычное приложение, без установки в систему. Команда `publish` собирает один самодостаточный `PCController.Server.exe`.

**Приложение** (нужны Node.js и Android-устройство или эмулятор):

```
cd PCController.Client
npm install
npm run android
```

Приложение использует нативные модули (`react-native-zeroconf`, `expo-clipboard`), поэтому запускается как собственная сборка (dev client), а не в Expo Go. APK для установки собирается через [EAS Build](https://docs.expo.dev/build-reference/apk/) (`eas build -p android --profile preview`).
